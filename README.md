## 📋 প্রকল্প বিবরণ

**সিলেট অনলাইন সার্ভিস বাংলাদেশ** একটি আধুনিক, ইউজার-ফ্রেন্ডলি ওয়েবসাইট যা সিলেট এবং আশেপাশের এলাকায় সকল ধরনের সরকারি ডিজিটাল সেবা প্রদান করে।

---

## 🎯 আমাদের সেবা সমূহ

1. **ই-পাসপোর্ট** - আপনার পাসপোর্ট আবেদন অনলাইনে সহজে সম্পন্ন করুন
2. **জন্ম নিবন্ধন** - নতুন জন্মের জন্য অনলাইন নিবন্ধন এবং সার্টিফিকেট
3. **জাতীয় পরিচয়পত্র সংশোধন** - জাতীয় পরিচয়পত্রের তথ্য সংশোধন করুন
4. **সার্টিফিকেট সংশোধন** - শিক্ষা ও অন্যান্য সার্টিফিকেটের তথ্য সংশোধন
5. **ড্রাইভিং লাইসেন্স** - নতুন ড্রাইভিং লাইসেন্স আবেদন এবং নবায়ন
6. **গ্রাহক সহায়তা** - আমাদের বিশেষজ্ঞ দল আপনার সেবায় নিয়োজিত

## 🚀 দ্রুত শুরু করুন

### পদ্ধতি ১: সরাসরি ফাইল খুলুন
১. `index.html` ডাউনলোড করুন
২. আপনার ব্রাউজারে খুলুন
৩. উপভোগ করুন! 🎉

### পদ্ধতি ২: লোকাল সার্ভার চালান

**Python ৩ দিয়ে:**
```bash
python -m http.server 8000
# তারপর ব্রাউজারে যান: http://localhost:8000
```

**Python ২ দিয়ে:**
```bash
python -m SimpleHTTPServer 8000
```

**Node.js দিয়ে:**
```bash
npx http-server
```
